# 外部业务同步总开关

`DASHBOARD_INTEGRATION_SYNC_ENABLED` 缺省/空值/`true` 保持原行为；只有显式 `false` 关闭外部业务同步。其他值（包括 `1`、大小写变体及空白）使 API、聚合 Worker 和告警 Worker 启动失败。三个进程共用同一运行文件/配置，不能只更新其中一个。

本开关与 `DASHBOARD_FINANCE_SOURCE` 和 `DASHBOARD_EMBED_ENABLED` 相互独立。平台+数析可明确选择 `false`、`standard`、`false`；已经安装其他业务系统的组合也可使用标准财务来源，同时保留外部合同/项目看板同步。默认不因目标网络失败推断产品未安装。

关闭后：

- 聚合 Worker 不读取/解析四种业务只读 DSN（CONTRACT/CRM/PROJECT/SETTLEMENT_READ_DSN），不创建外部数据库 Runner；不装配合同/项目 HTTP 请求、项目完整投影或合同历史导入摘要同步；不登记自动同步和队列消费任务。
- 聚合进程仍完成商业许可初始化并按原常驻/单次模式运行；不会移除 API、aggregation-worker、alert-worker 任何一个商业许可消费者。
- API 的外部来源列表及两个人工触发入口在原会话、权限、同源和许可门禁之后返回 `503 INTEGRATION_SYNC_DISABLED`，不会产生等待无人消费的新任务，也不把旧来源成功水位冒充当前仍启用。
- 不修改或清空 `sync_source/sync_job`、合同/项目/财务等既有快照，不标记旧任务成功或伪造导入回执。历史看板读、标准财务事实管理及发布仍按原权限和许可运行。
- 告警 Worker 本来只在数析自有聚合表上计算，继续保留本地评估、租户、业务时区及商业许可门禁；不受此开关关闭。

启用时沿用原外源配置完整性检查、机器凭据、只读权限、队列租约与幂等；关闭时忽略未使用外源配置（例如独立部署保留的项目 URL 或未填凭据），但仍核对自身数据库和业务配置。

关闭前必须按现有受控发布流程收口在途同步/历史合同导入及业务确认。此开关不是分布式取消或回执替代：新进程不继续领取旧队列，也不替换已冻结导入结果。重新启用后既有队列由原协议继续处理，必须事先评估在途状态；本功能不自动生成全历史重放任务。

本地 `compose.yaml` 将开关透传到三个业务进程；生产 profile/env 模板由平台受控配置交付。启停动作、迁移、备份和部署权限不由本开关授予。未执行真实业务库/外部服务验收。
